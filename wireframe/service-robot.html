SERVICE

ロボット導入・自動化支援

サービス概要

今ある設備を活かして、自動化を考える。

人手が足りない。手作業を減らしたい。夜間も機械を動かしたい。
自動化したい理由は、工場によってさまざまです。
シマモト技研では、今使っている機械や作業の流れ、設置スペースまで確認し、どこをどう自動化できるかを考えます。

工作機械を入れ替えることだけを前提にせず、既存設備を活かしながら、ロボットの選定・設計・据付・立ち上げ、その後のメンテナンスまで対応します。

FEATURES シマモト技研のロボット導入・自動化支援の特徴

FEATURE 01

今ある機械に、ロボットを組み合わせる。

自動化のために、すべての設備を入れ替える必要はありません。
今使っている工作機械の仕様や状態を確認し、後付けできるロボットや周辺設備を考えます。

CASE

  • 既存NC旋盤にロボットを後付けし、ワークの投入・取り出しを自動化。
  • 既存設備3台をロボット1台でつなぎ、搬送・着脱作業を自動化。
[ イメージ画像 ]
既存設備へのロボット後付け

FEATURE 02

人がやっている作業から、自動化できるところを探す。

ワークを運ぶ。機械に付ける。取り外す。次の工程へ運ぶ。
実際の作業を見ながら、人が付きっきりになっている工程や繰り返し作業を確認します。
ロボットを入れることありきではなく、どこを自動化すれば現場が楽になるかを考えます。

CASE

  • 手作業だったワーク供給を確認し、ロボット＋ストッカーによる自動供給を提案。
  • 工程間を何度も往復していた搬送作業を見直し、ロボット搬送へ変更。
[ イメージ画像 ]
現場作業の確認・分析

FEATURE 03

設計から立ち上げ、その後まで。

ロボットの配置だけでなく、ハンド、ストッカー、安全柵、ワークの流れまで含めて設計します。
製作、搬入・据付、ティーチング、試運転まで対応し、実際に現場で使える状態まで立ち上げます。

CASE

  • 既存ラインに合わせ、ロボット・安全柵・ストッカーまで含めてレイアウトを設計。
  • 機器選定からティーチング・試運転まで対応し、実際のワークで動作を確認して引き渡し。

MERIT 選ばれる理由

MERIT 01

工作機械ごと分かる

ロボットだけでなく、組み合わせる工作機械の仕様や状態まで見たうえで、自動化を考えられます。

MERIT 02

機械とロボットをまとめて任せられる

工作機械、ロボット、周辺設備、搬入・据付まで、窓口を分けずにまとめて進められます。

MERIT 03

導入した後も見てもらえる

ロボットの調整だけでなく、工作機械の修理・メンテナンスにも対応。
稼働後の不調や変更にも継続して対応します。

APPLICATION こんな作業、自動化できるかもしれません。

  • 工作機械への材料投入
  • 加工後のワーク取り出し
  • 機械間のワーク搬送
  • 人が付きっきりになっている作業
  • 重いワークの持ち運び
  • 夜間・長時間の連続運転
  • 今ある機械へのロボット後付け
  • 繰り返しの多い単純作業

「何を自動化すればいいか分からない」という段階でも、実際の作業を見ながら考えます。

FLOW 導入までの流れ

01

現場・作業の確認

ワークや作業内容を確認します。

02

設備・スペースの確認

今ある機械や設置場所を確認します。

03

自動化方法のご提案

ロボットや周辺設備の組み合わせを考えます。

04

設計・機器選定

ロボット、ハンド、安全設備などを決めます。

05

製作・事前調整

システムを製作し、動作を確認します。

06

搬入・据付

現場へ搬入し、既存設備と組み合わせます。

07

ティーチング・試運転

実際のワークで動きを調整します。

08

アフターサポート

導入後の調整やメンテナンスにも対応します。

SUBSIDY SUPPORT

補助金を使った自動化も、一緒に考えます。

ロボットや省力化設備の導入では、補助金を活用できる場合があります。

シマモト技研とゼロプラスグループが連携し、設備導入と補助金申請をまとめて進めます。

補助金活用支援について

※補助金の利用や採択を保証するものではありません。
制度の要件や公募期間は変更される場合があります。
