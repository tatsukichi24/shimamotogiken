SERVICE

工作機械販売

サービス概要

現場に合う一台を豊富な選択肢から。

加工内容や生産量、必要な精度、設置環境によって最適な工作機械は異なります。
シマモト技研では現場の条件を踏まえ中古工作機械を中心に最適な設備をご提案します。

機械の選定だけでなく、搬出・輸送、搬入・据付、立ち上げ、その後のメンテナンスまで対応。
機械を届けるだけではなく現場で使える状態まで一貫して支えます。

FEATURES シマモト技研の工作機械販売の特徴

FEATURE 01

幅広いラインナップと豊富な設備情報

各メーカーとのネットワークを活かし中古機械を中心に幅広い機種・設備情報を取り扱っています。

CASE

  • 複数の在庫情報を比較し条件・予算に合う一台をご提案。
  • 「この機械が出たら」とご相談いただき入荷時にご提案。

FEATURE 02

旋盤への深い知見と、長年の実績

長年にわたり旋盤を扱ってきた経験をもとに機種ごとの特徴や違いを踏まえた提案を行います。
加工内容や用途に合わせて現場に合う一台を見極めます。

CASE

  • 将来のロボット投入を想定し自動化しやすい旋盤と周辺構成を選定。
  • カム式自動盤の移設後レベル出しまで自社で対応。

FEATURE 03

機械選びの先にある工程改善まで考える

加工内容や生産量、段取り替えの頻度まで確認し機械単体ではなく工程全体を見て提案します。
この先のロボットや周辺設備も組み合わせ省人化・自動化まで見据えます。

CASE

  • ワーク着脱をロボット化し夜間の無人運転を想定。
  • 複数工程を見直し機械・ロボットを組み合わせて工程集約。

MERIT 選ばれる理由

MERIT 01

設備選定ミスの削減

メーカーの枠にとらわれず、複数メーカー・機種を比較しながら、現場条件に合う設備を選定します。

MERIT 02

導入工数・調整負担の削減

機械探しから選定、搬入・据付までまとめて相談でき、複数業者との調整負担を軽減します。

MERIT 03

省人化・自動化の推進

数多くの現場で培ってきた知見をもとに、設備単体ではなく工程全体を見据えた改善提案につなげます。

USED MACHINE

中古機械をお探しの方へ

シマモト技研が取り扱う中古工作機械の在庫情報は「中古機械百貨店」でご覧いただけます。

中古機械を探す ※外部サイト「中古機械百貨店」へ移動します。

FLOW 工作機械導入の流れ

01

ご相談・ヒアリング

加工内容、ワーク、生産量、必要精度、ご予算などを確認します。

02

設備選定・ご提案

在庫情報やメーカーとのネットワークから条件に合う設備をご提案します。

03

機械確認・お見積り

機械の状態や仕様を確認し導入条件を含めてお見積りします。

04

搬出・輸送

設備の搬出から輸送まで手配します。

05

搬入・据付

現場への搬入・据付レベル出しなどを行います。

06

立ち上げ

動作確認・試運転を行い現場で使用できる状態までつなげます。

07

アフターサポート

導入後の修理・メンテナンス設備更新や自動化のご相談にも対応します。

SUPPORT

導入後も長く使い続けるために。

メーカーサポートが終了した旧型機や長年使用してきた工作機械についても現在の状態を確認し修理やオーバーホールの方法を検討します。

中古機械の導入後も点検・修理・メンテナンスを通じて設備の安定稼働を支えます。
