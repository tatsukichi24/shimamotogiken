SERVICE

廃業支援サービス

サービス概要

ものづくりの幕引きに、最後まで伴走する。

工場を閉じると決めても、何から始めればいいのか分からない。
機械の売却、在庫や材料の整理、搬出・撤去、原状回復、各種手続きまで、廃業には多くの対応が必要です。

シマモト技研では、設備の査定・買取から工場内の整理、搬出・撤去、原状回復、その後の手続きまでまとめて対応します。
相談先をいくつも探す必要はありません。
廃業に必要なことを整理しながら、工場の明け渡しまで一緒に進めます。

FEATURES シマモト技研の廃業支援サービスの特徴

FEATURE 01

廃業に必要なことを、まとめて任せられる。

機械の売却、工場内の片付け、搬出、撤去、原状回復、各種手続き。
それぞれ別の業者へ依頼するのではなく、シマモト技研が窓口となってまとめて進めます。

CASE

  • 従業員20名規模の金属加工工場で、設備買取から工場の明け渡しまで一括対応。
  • 閉鎖まで3か月の工場で、設備売却・片付け・撤去・原状回復をまとめて進行。
[ イメージ画像 ]
廃業対応のご相談

FEATURE 02

工場に残ったものを、まとめて整理。

工作機械だけでなく、周辺設備、鋼材、工具、治具、仕掛品、不要品まで。
工場内を確認し、売るもの、移すもの、処分するものに分けながら整理します。
何を残し、何を処分すればいいか分からない状態からでも進められます。

CASE

  • NC旋盤やマシニングセンタ約20台を、買取・移設・処分に振り分けて整理。
  • 鋼材、治具、工具、仕掛品まで仕分けし、設備搬出とあわせて工場内を整理。
[ イメージ画像 ]
工場内設備の仕分け・整理

FEATURE 03

手続きや専門家とのやり取りも、窓口をひとつに。

廃業には、工場の片付けだけでなく、さまざまな手続きが必要になります。
専門家が必要な内容は、グループ各社や外部の専門家と連携。
お客様がそれぞれの相談先を探し回らなくても済むよう、窓口をまとめて進めます。

CASE

  • 後継者不在による廃業で、設備整理と並行して専門家との各種手続きを連携。
  • 工場撤去に活用できる補助制度を確認し、申請から撤去完了まで支援。

MERIT 選ばれる理由

MERIT 01

何から始めればいいか分からなくても進められる

廃業時期や工場の状況を確認し、必要なことと進める順番から整理します。

MERIT 02

何社もの業者とやり取りしなくていい

設備買取、片付け、搬出、撤去、原状回復、専門家との連携まで、窓口をまとめられます。

MERIT 03

売れるものは売り、残ったものまで整理できる

工作機械を扱ってきた経験を活かし、価値のある設備を見極めながら、買取・移設・処分を振り分けます。

FLOW ご依頼の流れ

01

ご相談

廃業時期や工場の状況を伺います。

02

現地確認

設備・在庫・工場内を確認します。

03

進め方・お見積り

必要な作業と進め方を整理します。

04

設備買取・工場内整理

機械・在庫・不要品を整理します。

05

搬出・撤去・原状回復

設備搬出から原状回復まで対応します。

06

各種手続き・専門家連携

必要な手続きや専門家連携を進めます。

07

明け渡し・完了

最後の確認まで一緒に進めます。
