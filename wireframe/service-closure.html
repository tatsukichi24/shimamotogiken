SERVICE

廃業支援サービス

サービス概要

ものづくりの幕引きに最後まで伴走する。

工場の廃業には機械・設備の売却だけでなく、在庫や材料の整理、搬出、原状回復、解体、各種手続きなど、さまざまな対応が必要です。

シマモト技研では設備の査定・買取から工場内の整理、搬出・撤去、その後の手続きまで一貫して支援。
製造現場を知る立場から廃業に必要な対応をひとつずつ整理し最後まで伴走します。

FEATURES シマモト技研の廃業支援サービスの特徴

FEATURE 01

廃業に必要な対応を一貫してサポート

設備の査定・買取から工場内の整理、搬出・撤去、原状回復、各種手続きまで。
廃業に伴って発生するさまざまな対応をひとつの窓口でまとめて支援します。

CASE

  • 従業員20名規模の金属加工工場で設備買取から原状回復まで一括対応。
  • 工場閉鎖まで3か月の案件で設備売却・撤去・明け渡しまで工程を一元管理。
[ イメージ画像 ]
廃業対応のご相談

FEATURE 02

機械・在庫・工場内設備をまとめて整理

工作機械や周辺設備、材料、在庫、不要品まで工場内に残るものを一括して整理。
売却・移設・撤去・処分を振り分けながら工場の明け渡しに向けて進めます。

CASE

  • NC旋盤やマシニングセンタ約20台を買取・移設・処分に振り分けて整理。
  • 鋼材・治具・工具・仕掛品を仕分けし設備搬出と並行して撤去。
[ イメージ画像 ]
工場内設備の仕分け・整理

FEATURE 03

専門家と連携し廃業手続きまで支援

廃業に伴う各種手続きや制度活用など必要に応じて専門家やグループ各社と連携。
現場の整理だけでなく廃業完了まで伴走します。

CASE

  • 後継者不在の廃業で設備整理と専門家による各種手続きを連携。
  • 工場撤去に活用できる補助制度を検討し申請から撤去完了まで支援。

MERIT シマモト技研に相談するメリット

MERIT 01

廃業にかかる負担を軽減

複数の業者や専門家へ個別に依頼する必要がなく廃業に必要な対応をまとめて相談できます。

MERIT 02

設備・資産の価値を最大限に活用

売却できる機械や設備を見極め買取・移設・処分を適切に振り分けることで、廃業時の負担軽減につなげます。

MERIT 03

廃業後まで見据えた安心感

設備整理や各種手続きをまとめて進めることで抜け漏れや手戻りを防ぎ、廃業後に不安を残さないかたちを目指します。

FLOW ご依頼の流れ

01

ご相談・状況確認

廃業時期や工場の状況を確認します。

02

現地調査・設備査定

設備・在庫・残置物を確認します。

03

廃業計画・お見積り

進め方と費用をご提案します。

04

設備買取・工場内整理

機械・在庫・不要品を整理します。

05

搬出・撤去・原状回復

設備搬出から原状回復まで対応します。

06

各種手続き・専門家連携

必要な手続きや専門家連携を進めます。

07

工場明け渡し・廃業完了

明け渡しから完了まで支援します。
